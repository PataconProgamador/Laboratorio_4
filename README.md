# MySql (Laboratorio 4)
-----------------
25/09/26.  
## Contenido  
MySQL: Windows form application, funciona como un registro de productos Nombre, precio, Cantidad, Folio e Imagen vinculados a una base de datos de MySQL. 
Con funciones de Guardar, Modificar, Borrar y Limpiar.

## Tecnologias  

Lenguaje: C#, SQL.    
Herramientas: Visual Studio, GitHub, Virtual UTP, MySQL.
